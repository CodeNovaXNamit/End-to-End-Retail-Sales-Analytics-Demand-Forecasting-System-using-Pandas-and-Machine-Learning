# Retail Demand Forecasting & Sales Intelligence (AI/ML)

This project builds an end-to-end data analytics and machine learning pipeline on real retail sales data.
It covers:
- Data cleaning and preprocessing (Pandas)
- Exploratory Data Analysis (EDA)
- Feature engineering
- Demand forecasting using ML models
- Evaluation and insights
